# Hava Durumu Portalı

Bu proje basit bir hava durumu uygulamasıdır. Şehir seçerek anlık hava durumunu öğrenebilirsiniz.

## Kurulum

1. Projeyi klonlayın:
https://github.com/beyzaozcan0/hava-durumu-portali

2. frontend klasörüne gidin:
Terminale 'cd frontend' yazın.

3. Gerekli paketleri yükleyin:
npm install
npm install react react-dom
npm install lottie-react
npm install cors

4. weather-app klasörüne gidin:
Terminale 'cd weather-app' yazın.

5. weather-app içindeki src klasörüne gidin:
Terminale 'cd src' yazın.

6. Gerekli paketleri yükleyin:
pip install flask

7. frontend klasöründe terminale 'npm start' yazın.

8. weather-app klasöründe terminale 'python main.py' yazın.

9. Açılan ekranda arama çubuğuna hava durumunu öğrenmek istediğiniz şehri/ülkeyi girip Bul'a tıklayın.

10. Çıkan weather card'taki sağ üst köşeden istediğiniz şehri favori listenize ekleyin ya da çıkarın.

11. Ekranın sağ üst köşesinden Favorilerim kısmından eklediğiniz şehirleri kontrol edin.
